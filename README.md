# ModOS

Research project: **ModOS: Exploring On-Demand Spatial Interfaces in Mixed Reality**. One repo (`github.com/ziru-wei/intelligent-spatial-interface`, branch `modos-live-input`), published as the project's site: `index.html` is its page.

| Folder | What |
| --- | --- |
| `index.html` | The main page, opened by `npm start` in `system/editor`: Demo (ModOS live, needs the system), Gallery (recordings of every MOD), Vocabulary, About |
| `system/` | The prototype: web editor, ModOS pipeline, Vision Pro app |
| `media/gallery/` | The Gallery's examples and their stills |
| `context/` | The design doc; About's text (`about/`); the paper draft and study plans stay private (not in git) |

- Start here: `AGENTS.md` (how to run, code map, decisions, next steps).
- The spec: `context/docs/modos-system-design.md`.
